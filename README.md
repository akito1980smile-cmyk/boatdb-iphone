# iPhone対応 競艇公式データベース（初期版）

全国24場の公式ダウンロードファイルを取得し、Excel/CSVに変換するWebアプリです。

## 実装済み
- iPhone Safari対応UI、ホーム画面追加用マニフェスト
- 日付範囲選択（最大31日）、競走成績/番組表切替
- 公式サイトのLZH取得、サーバー側での展開、CP932復号
- 公式ファイルの**行単位原文**をExcel/CSV出力（原文保持、項目解析なし）
- ファイル不在・接続失敗・解凍失敗時のエラー表示

## 未実装・制限
- 固定長レイアウトからの着順・選手名等の構造化解析
- 競艇場別フィルター（画面は全国一括のみ）
- 過去全期間の自動一括収集、DB保存、データ検索、オッズ取得、定期自動更新
- 公式データが存在する最古の日付の自動判定
- サーバーへのデプロイ（ユーザーのホスティング環境が必要）

## 起動方法
Dockerが使える環境で:
```bash
docker build -t boatdb-iphone .
docker run --rm -p 8000:8000 boatdb-iphone
```
http://localhost:8000 にアクセスしてください。iPhoneから使う場合はHTTPS公開が必要です。Render/Railway等のDocker対応サービスに本フォルダをGitHub経由でデプロイしてください。**GitHub Pages単体ではPythonサーバーを動かせません。**

## データ出典
https://boatrace.jp/owpc/pc/extra/data/download.html
公式配布データは日付別LZHです。第三者による配布規則の記載を参考にしています。取得先URLや配布仕様が変わると動作しなくなる場合があります。サイト利用規約・アクセス制限を確認し、負荷のかかる一括取得を避けてください。

※ 実データの取得・解凍について、制作環境からの実通信を伴う動作確認は未実施です。
